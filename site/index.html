What this earns

The abstract model supports a narrow mechanism: retained branch history becomes recoverable through selected somatic sums, and retaining previous answers modestly improves which gate is chosen next. Reads can also disturb that memory.

This uses linear leaky traces, a programmed gate selector, a correct model and a known eight-history dictionary. It does not establish a learned neural gate, spike-waveform communication, unknown-history recovery or a new AI architecture. Twelve branch values are accompanied by 96 candidate-state values, eight belief values and shared model/catalogue storage in the observer. Selection evaluates all 24 candidate gates; computation is not matched to random selection.

The original PerceptionLab ecg.json accident supplies the historical question about observation inside feedback. Its aliasing/variance-controller pulse has different equations. AnttisBrain2's moons, MovingTarget2 and BrainAsInverseModeler remain distinct contributors to this test.
